  • 두 표기 모두 배열의 원소를 읽거나 변경할 수 있음.
  • 함수 밖의 배열 int q[3]과 포인터 변수 int *p는 서로 다른 자료형.

배열을 읽기만 할 때: const

#include <stdio.h>

배열 복사: copy_array

Code

c
void copy_array(const int *src,
                int *dest, int count) {
    for (int i = 0; i < count; i++)
        dest[i] = *(src + i);
}
int main(void) {
    int q[] = {10, 20, 30};
    int count = sizeof q / sizeof q[0];
    int copy[count];
    copy_array(q, copy, count);
}
  • src는 원본, dest는 복사할 배열의 첫 원소.
  • i = 0에서 10을 복사하고, count개 원소를 차례로 복사.
  • 복사 후 두 배열의 저장 공간은 별개.

팩토리얼: 같은 규칙으로 더 작은 문제 풀기

3!=3×2×1=63! = 3 \times 2 \times 1 = 6 3!=3×2×1=6

  • 3!=3×2!3! = 3 \times 2!3!=3×2!: 2!2!2!의 값이 필요.
  • 2!=2×1!2! = 2 \times 1!2!=2×1!, 1!=1×0!1! = 1 \times 0!1!=1×0!: 한 단계씩 작아짐.
  • 0!=10! = 10!=1: 더 작은 문제를 호출하지 않는 종료 조건.

#include <stdio.h>
int factorial(int n) {
