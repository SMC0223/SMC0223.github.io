형 변환

자동(묵시적) 형 변환

  • C의 규칙에 따라 자료형을 자동으로 변환함.
c
double a = 30 / 180.0;
단계 계산 과정
1 180.0의 자료형은 double
2 30을 double로 자동 변환
3 실수 나눗셈 결과를 a에 저장

결과: 약 0.166667 · double

강제(명시적) 형 변환

  • (자료형)으로 변환할 자료형을 직접 지정함.
c
double a = (double)30 / 180;
단계 계산 과정
1 (double)30으로 직접 변환
2 180도 double로 자동 변환
3 실수 나눗셈 결과를 a에 저장

결과: 약 0.166667 · double

(double)(30 / 180)은 정수 나눗셈 후 변환하므로 0.0. 이미 제거된 소수 부분은 복원 불가.

scanf 구조: 형식 문자열과 저장 위치의 연결

printf는 변수의 값 전달, scanf는 값을 저장할 변수의 주소 전달. double 입력은 %lf 사용.

C ProgrammingWEEK 03

scanf 기본 구조

c
int motor = 0;
int matched = scanf("%d", &motor);

입력 예: 20

구성 요소 역할
%d 정수 형식으로 읽기
&motor 읽은 값을 저장할 변수의 주소
반환값 matched 성공적으로 값을 대입한 항목 수
  • 성공하면 motor에 20, matched에 1 저장.
  • 숫자 대신 abc 입력 시 변환 실패. 반환값 0, motor에는 새 값이 저장되지 않음.
  • 이번 실습은 자료형의 범위 안에서 올바른 형식으로 입력하는 조건으로 진행.

입력 실패 처리와 조건문은 이후 단원에서 학습.

C ProgrammingWEEK 03
WEEK 03

왜 &를 사용할까?

표현 전달하는 것 예
motor 변수에 저장된 값 printf("%d", motor);
&motor 값을 저장할 변수의 주소 scanf("%d", &motor);
  • scanf가 호출한 쪽의 변수를 변경하려면 저장 위치가 필요함.
  • scanf("%d", motor);는 정수 변수의 주소 전달 방식이 아님.
  • &는 여기서 주소를 구하는 단항 연산자. a & b의 비트 AND와 구분.

배열·포인터의 상세 원리는 이후 단원에서 학습. 문자열 배열 입력은 뒤의 별도 예 참고.

printf와 scanf 비교

변수 자료형 printf 출력 scanf 입력
int n printf("%d", n); scanf("%d", &n);
unsigned int n printf("%u", n); scanf("%u", &n);
float f printf("%f", f); scanf("%f", &f);
double d printf("%f", d); scanf("%lf", &d);
char c printf("%c", c); scanf(" %c", &c);
  • double 입력은 %lf, 출력은 %f 사용.
  • scanf의 " %c"는 문자 앞의 공백·개행을 건너뜀.
  • scanf에는 %.2f처럼 소수 자릿수를 지정하지 않음.

문자와 문자열 입력: %c와 %s

대상 저장 공간 입력 형식 출력 형식
모드 한 글자 char mode = ' '; scanf(" %c", &mode); %c
공백 없는 이름 char name[16] = ""; scanf("%15s", name); %s
  • " %c": 앞의 공백·개행을 건너뛰고 문자 하나 읽기. "%c"는 공백도 읽음.
  • char name[16]: 16바이트 저장 공간. %15s는 최대 15바이트를 읽고 끝 표시 \0 추가.
  • 문자열 배열 이름은 저장 위치로 전달되므로 이 예시에서는 &name이 아닌 name 사용.
  • %s는 공백에서 읽기 종료.

배열의 상세 문법은 이후 학습. 여기서는 크기가 정해진 이름 저장 공간으로 사용.

16진수 이해하기

10진수 2진수 · 4비트 16진수 10진수 2진수 · 4비트 16진수
0 0000 0 8 1000 8
1 0001 1 9 1001 9

6 0110 6 14 1110 E

  • 16진수는 0~9, A~F 사용. A~F는 10진수의 10~15에 대응.
  • 16진수 1자리 = 2진수 4자리. 0010 1010₂ → 2A₁₆ → 2 × 16 + 10 = 42₁₀.
  • C 코드에서는 0x2A로 표기. 같은 정수 값을 %u로 출력하면 42, %X로 출력하면 2A (unsigned int 기준).

16진수 입력: %x로 읽고 원하는 진법으로 출력

항목 코드 또는 입력 의미
저장 변수 unsigned int value = 0; 부호 없는 정수 값 저장

2진수 출력 (value >> n) & 1u n번째 비트를 꺼내 0 또는 1 출력
