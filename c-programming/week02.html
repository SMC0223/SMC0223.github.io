변수(variable)와 자료형(type) 이해하기

이진법

  • 0과 1로 수를 표현함. 각 자리의 값은 오른쪽부터 1, 2, 4, 8… 순서.
10진수 자리 값의 합 이진수 표현
10 8 + 2 = 2³ + 2¹ 00001010
8 8 = 2³ 00001000
5 4 + 1 = 2² + 2⁰ 00000101
127 64 + 32 + 16 + 8 + 4 + 2 + 1 01111111
255 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 11111111
65535 2¹⁵ + 2¹⁴ + … + 2⁴ + 2² + 2⁰ 11111111 11111111
  • 큰 값을 표현하기 위해서는 많은 수의 bit가 필요.

255 이하의 예시는 1바이트(8비트), 65525 예시는 2바이트(16비트)로 표시함. 앞쪽의 0은 자리 채움용.

이진법으로 소수 표현하기

  • 소수점 오른쪽으로 갈수록 자리 값이 **1/2, 1/4, 1/8, 1/16…**로 작아짐.
  • 2⁻¹ = 0.5, 2⁻² = 0.25, 2⁻³ = 0.125. 1이 있는 자리의 값을 더해 계산함.
10진수 자리 값의 합 이진수 표현
0.5 1/2 = 2⁻¹ 0.1₂
0.25 1/4 = 2⁻² 0.01₂
0.125 1/8 = 2⁻³ 0.001₂
0.75 1/2 + 1/4 = 0.5 + 0.25 0.11₂
1.5 1 + 1/2 1.1₂
5.75 4 + 1 + 1/2 + 1/4 101.11₂
  • 101.11₂는 정수 부분 101₂ = 5, 소수 부분 0.11₂ = 0.75를 합친 값.
  • 5.76은 이진수로 표현하면 소수 부분이 끝없이 반복됨.

아래첨자 ₂는 이진수 표시. 표는 수를 이진법으로 나타낸 예이며, float·double의 실제 메모리 저장 형식과는 구분함.

변수 값 변경: 같은 객실, 새로운 손님

다른 손님이 온다면?

C언어에서는 이것을 '대입'이라고 함

  • =: 오른쪽 값을 왼쪽 변수에 저장함.
  • 값 변경 시 자료형을 다시 쓰지 않음.
  • 대입 후 room101의 현재 값: 5

대입은 값을 복사한다

분신술을 쓰는 손님이 호텔에 왔다!

얼굴에 10이 적힌 손님이 101호에 체크인함.

분신을 만든 뒤에는 각자 지냄

c
unsigned short room101 = 10;
unsigned int room102 = room101;
room101 = 20;
손님 이야기 room101 room102
손님이 101호에 체크인 10 아직 선언 전
분신이 102호에 체크인 10 10
101호 숫자만 20으로 변경 20 10
  • 분신은 만들어진 순간의 숫자 10을 가짐.
  • 이후 원래 손님이 바뀌어도 분신은 그대로임.

대입은 그 순간의 값을 복사함. 이후 두 변수는 독립적임.

자료형(Data Type)

자료형 = CPU호텔의 방 종류 + 방 크기

자료형(방 종류) 저장할 값 일반 크기(방 크기) 선언과 초기화 예시 printf
int 부호 있는 정수 4바이트 int num = 2; %d
unsigned int 부호 없는 정수 4바이트 unsigned int count = 10u; %u
float single precision 4바이트 float temp = 23.5f; %f
double double precision 8바이트 double e = 2.718281828459045; %f
char 문자 코드 또는 작은 정수 1바이트 char c = 'A'; %c
bool 0 또는 1 1바이트 bool isOpen= 0; %d
  • 자료형은 "스위트, 디럭스, 일반" 룸 처럼 데이터의 형태(정수형, 실수형 등)를 구분한 것
  • 방들은 서로 다른 크기 형태를 가지고 있는 것처럼 자료형은 서로 다른 메모리 크기를 할당.
  • 'unsinged'는 부호가 없음을 의미

표는 1바이트 = 8비트인 일반적인 PC 환경 기준.

C11에서 bool 사용 시 <stdbool.h>를 포함해야 함.

정수형 자료형의 종류

자료형 일반 크기 부호 있는 값의 범위 printf
char 1바이트 −128 ~ 127 %hhd
short 2바이트 −32,768 ~ 32,767 %hd

부호가 있는 정수, 2의 보수

1byte(8bit)로 −128 ~ 127까지 표현

비트 표현 정수 값
00000000 0
00000101 +5
01111111 +127 · 최댓값
10000000 −128 · 최솟값
11111011 −5
11111111 −1
  • 맨 왼쪽 비트가 0: 0 또는 양수.
  • 맨 왼쪽 비트가 1: 음수.

+5를 −5로 바꾸기

단계 8비트 표현
① +5를 이진수로 표현 00000101
② 모든 비트를 뒤집음 11111010
③ 1을 더함 → −5 11111011

2의 보수: 비트를 뒤집고 1을 더함.

  • 각 비트의 자리 값: −128, 64, 32, 16, 8, 4, 2, 1.
  • 11111011 = −128 + 64 + 32 + 16 + 8 + 2 + 1 = −5.

8비트 signed char를 2의 보수로 표현하는 예. 같은 비트도 자료형에 따라 다르게 해석됨.

실수형 자료형의 종류: float, double, long double

float와 double: π로 이해하는 정밀도의 차이

원주율 π = 3.14159265358979323846…

c
float pi_f = 3.14159265358979323846f; // float형은 숫자 다음에 f를 붙인다.
double pi_d = 3.14159265358979323846;
printf("float : %.15f\n", pi_f); // float형 값을 소수점 15자리까지 표시
printf("double: %.15f\n", pi_d); // double형 값을 소수점 15자리까지 표시

출력 예 · 소수점 아래 15자리:

text
float : 3.141592741012573
double: 3.141592653589793
  • float는 π의 3.141592 뒤부터 숫자가 달라짐.
  • double은 float보다 더 낮은 소수점 자리(이진수 기준)에서 반올림하여 저장.
  • 같은 π를 저장해도 double이 더 많은 자릿수를 정밀하게 표현함.

자료형에 따라 저장 정밀도가 다름. 출력 자릿수를 늘려도 저장 정밀도가 높아지지는 않음.

부동소수점 방식의 이해(생략)

부동소수점(floating point): 숫자의 세부 값과 소수점 위치를 나누어 표현하는 방식.

구성 역할 float · 32비트 double · 64비트
부호(sign) 수의 부호 표현 · 0은 양의 부호, 1은 음의 부호 1비트 1비트
지수(exponent) 2의 거듭제곱으로 수의 크기 조절 8비트 11비트
가수부(fraction) 유효숫자의 세부 자릿수 저장 23비트 52비트

예: 5.75 = 101.11₂ = 1.0111₂ × 2²

text
float:  0  |  10000001  |  01110000000000000000000
       부호     지수              가수부
  • 지수 2에 보정값 127을 더한 129를 저장함 → 10000001₂.
  • 정규화된 수의 맨 앞 1은 생략함 → 실제 유효숫자는 24비트 / 53비트.

double은 세부 숫자를 담는 비트가 더 많아 정밀도가 높음. π처럼 자릿수가 끝없이 이어지는 값은 공간에 맞춰 반올림하여 저장함.

논리 조건을 쓸 때: 범위와 평가 순서

c

오른쪽 이동: 2로 계속 나누기

단계 하위 8비트 비트 이동 정수 나눗셈
시작 00001101 13 —
오른쪽 1칸 00000110 13u >> 1 → 6 13u / 2u → 6
오른쪽 2칸 00000011 13u >> 2 → 3 13u / 4u → 3
오른쪽 3칸 00000001 13u >> 3 → 1 13u / 8u → 1
오른쪽 4칸 00000000 13u >> 4 → 0 13u / 16u → 0
  • 한 칸씩 이동하면 13 → 6 → 3 → 1 → 0으로 변화함.

  • 부호 없는 정수 기준. 음수의 오른쪽 이동에 같은 규칙을 적용하지 않음.

각 링크의 가로·세로 성분을 더함

  • l1l_1l1​, l2l_2l2​: 팔의 길이. 단위 m.
  • θ1\theta_1θ1​: +x축 기준 각도.
  • θ2\theta_2θ2​: 첫 번째 팔 기준의 상대 각도.

x1=l1cos⁡θ1,y1=l1sin⁡θ1x2=x1+l2cos⁡(θ1+θ2)y2=y1+l2sin⁡(θ1+θ2)\begin{aligned} x_1 &= l_1\cos\theta_1,\quad y_1 = l_1\sin\theta_1 \\[0.8em] x_2 &= x_1 + l_2\cos(\theta_1+\theta_2) \\[0.8em] y_2 &= y_1 + l_2\sin(\theta_1+\theta_2) \end{aligned} x1​x2​y2​​=l1​cosθ1​,y1​=l1​sinθ1​=x1​+l2​cos(θ1​+θ2​)=y1​+l2​sin(θ1​+θ2​)​

  • cos → 가로 성분, sin → 세로 성분.
