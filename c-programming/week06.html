01. 반복문 안의 반복문

중첩 for문의 구조

  • 중첩 반복문: 반복문의 본문 안에 다른 반복문을 배치한 구조.
  • 반복 변수는 바깥에서부터 i → j → k 순서로 사용하는 경우가 많음.
  • 격자 출력 예시: i는 행, j는 열의 진행 상태 저장.
C ProgrammingWEEK 06
WEEK 06

구구단: 한 단을 끝내고 다음 단으로

i는 단, j는 곱할 수

  1. i = 2로 2단 시작.
  2. j = 1부터 9까지 증가하며 2 × j 출력.
  3. j = 10이면 안쪽 조건 거짓 → 2단 종료.
  4. i++로 다음 단 선택, j를 다시 1로 초기화.
  5. 같은 과정을 반복하여 9단까지 출력.
  • 한 단의 곱셈을 모두 마친 뒤 다음 단 선택.
  • 바깥 반복은 단, 안쪽 반복은 해당 단의 곱셈 관리.
C ProgrammingWEEK 06
WEEK 06

실행 추적: 2단부터 9단까지

c
for (int i = 2; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
        printf("%d x %d = %d\n",
               i, j, i * j);
    }
}
  • 한 단 안에서는 i 고정, j만 증가.
  • 2단 종료 후 i는 3, j는 다시 1.
출력 순서 i: 단 j: 곱할 수 출력

72 9 9 9 x 9 = 81

무한 반복 1: 안쪽 변수 j가 진행하지 못함

목표: 별 5개씩 3행 출력

c
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 5; ) {
        printf("*");
    }
    printf("\n");
}
  • 안쪽 for의 증감식 누락.
  • 본문에서 j = 1을 반복하는 경우도 같은 유형.
단계 i j 결과·다음 동작
안쪽 초기화 1 1 j <= 5 검사
조건 검사 1 1 참 → 별 출력
별 출력 후 1 1 증감 없이 조건 재검사
다시 조건 검사 1 1 계속 참 → 별 출력 반복
  • j가 계속 1 → 조건이 거짓이 되지 않음.
  • 줄바꿈과 바깥 반복의 i++에 도달하지 못함.

무한 반복 2: 안쪽에서 바깥 변수 i 변경

목표: 별 5개씩 3행 출력

c

    for (int j = 1; j <= 5; j++) {
        printf("*");
        i = 1;
    }
    printf("\n");
}
  • 안쪽 본문에서 바깥 반복 변수 i를 다시 1로 변경.
단계 i 다음 동작
첫 행의 안쪽 본문 1 j는 5까지 증가
안쪽 반복 종료 후 1 줄바꿈
바깥 증감식 i++ 2 i <= 3 참
다음 행의 안쪽 본문 1 i = 1로 되돌림
안쪽 반복 종료 후 1 다시 줄바꿈
바깥 증감식 i++ 2 같은 과정 반복
  • 안쪽 반복은 정상적으로 종료 → 별 5개와 줄바꿈 반복.

#include <stdio.h>
void main() {

        for (b = 1; b <= a; b++) {
            printf("%c", Sh[a-b]);

정렬의 의미와 선택 정렬의 진행 방법

정렬: 기준에 따라 값의 순서 재배치

  • 오름차순: 작은 값부터 큰 값 순서.
  • 내림차순: 큰 값부터 작은 값 순서.
  • 예: 5 3 4 1 2 → 1 2 3 4 5.

선택 정렬: 남은 값 중 최솟값 선택

  1. 정렬할 구간의 첫 위치를 i로 지정.
  2. i부터 끝까지 비교하여 최솟값 위치 탐색.
  3. 최솟값과 i 위치의 값을 교환.
  4. i를 한 칸 옮겨 같은 과정 반복.

오름차순 정렬: 한 번에 한 자리 확정

  • 앞쪽은 정렬이 끝난 구간, 뒤쪽은 탐색할 구간.
  • 최솟값이 이미 i 위치에 있으면 제자리 유지.
  • 마지막 한 자리는 자동 확정.

개념 기억할 내용
배열 선언 같은 자료형의 여러 값 저장. int, float, double, char 사용
초기화·대입 선언 시 {...}로 초기화, 선언 후 a[i] = 값;으로 원소에 대입

원소 출력 a[i]로 접근, 정수 %d·실수 %f·문자 %c로 출력
