교과목 개요

수업 목표

본 교과목은 C언어의 기본 문법과 프로그래밍 기법을 학습하고, 이를 활용하여 다양한 공학 문제를 해결할 수 있는 프로그래밍 능력을 기르는 것을 목표로 함.

프로그래밍이란?

C언어

  • 1970년대 초, 데니스 리치가 개발(The C Programming Language)
  • 운영체제, 임베디드 시스템 프로그래밍 등에 자주 사용

C 언어 특징

  • 절차지향 언어, 빠르고 효율적
  • 간결한 문법 + 직접 메모리 제어 가능
  • 이식성이 매우 높음

주요 활용 분야

  • 운영체제 개발, 임베디드 시스템
  • 컴파일러 개발
  • 실시간 모터 제어기, 로봇 제어기 등

1세대 언어(1GL)

  • 기계어: CPU가 직접 처리할 수 있는 2진수(0과 1) 형태의 언어.

2세대 언어(2GL)

  • 어셈블리어: 기계어 명령을 간단한 영문 기호(ADD, SUB 등)로 매핑하여 인간의 관점에서 사용하기 편해진 저급 프로그래밍 언어.
  • 어셈블러를 통해 기계어로 번역됨.

3세대 언어(3GL)

  • 고급 프로그래밍 언어: C, C++, Java, Python, Pascal 등 인간이 이해하기 쉬운 문장 형태로 작성하는 언어.
  • 컴파일러나 인터프리터를 통해 기계어로 번역됨.

4세대 언어(4GL)

  • 비절차적·특수 목적 언어: SQL, PL/SQL, ABAP, Unix Shell, R, Halide, Oracle Reports 등.
  • '어떻게(How)'가 아니라 '무엇을(What)' 할지 명시하여 개발 생산성을 극대화한 언어.

5세대 언어(5GL)

  • 인공지능 및 제약 조건 기반 언어: Prolog, OPS5, Mercury, CVXGen, Geometry Expert 등.

컴퓨터가 실행할 수 있는 명령

번역 과정을 거쳐 프로세서(CPU)가 이해할 수 있는 기계어로 번역.

사람의 언어를 컴퓨터는 곧바로 이해할 수 없기 때문에 번역 과정이 필요.

C 프로그램의 실행 과정

%%{init: {"themeVariables":{"fontSize":"20px"},"flowchart":{"padding":14,"nodeSpacing":32,"rankSpacing":36}}}%% flowchart LR A[소스 코드 작성 <br>main.c] -- 컴파일 --> B[목적 파일 <br>main.o] B -- 링크 --> C[실행 파일] C -- 실행 --> D[출력 결과]

  • 컴파일(Compile)은 작성한 C 소스 코드를 컴퓨터가 처리할 수 있는 목적 파일(Object File)로 변환하는 과정. 이 과정에서 문법 오류와 자료형 등을 검사.

  • 링크(Link)는 생성된 목적 파일과 필요한 라이브러리를 서로 연결하여 하나의 실행 파일(Executable File)을 만드는 과정.

  • 실행(Execute)은 완성된 실행 파일을 메모리에 불러와 CPU가 명령어를 순서대로 수행하는 과정.

코드 설명

#include <stdio.h>

"stdio.h"라는 파일을 현재 코드에 포함.

main함수

c언어에서 가장 먼저 실행되는 함수

설명
int main(void){ return 0; }

int: 정수형 기본 자료형(-2^31,...-1,0,1,...,2^31-1)

void: 없음을 뜻하는 자료형.

return 0: 함수의 결과는 0이다.

즉 입력은 없고 출력은 항상 0인 함수

오늘의 핵심

프로그래밍과 C언어

  • 프로그래밍은 문제를 분석하고 해결 절차를 설계한 뒤, 프로그래밍 언어로 표현하는 과정임.
  • C언어는 운영체제, 임베디드 시스템, 로봇 등 다양한 분야의 기초가 되는 언어임.
  • C 프로그램은 main() 함수에서 시작하며, 각 명령문은 세미콜론(;)으로 끝남.

작성한 코드가 실행되기까지

  • 소스 파일(.c)은 컴파일과 링크 과정을 거쳐 실행 파일(.exe)로 변환됨.
  • VS Code에서 F5를 누르면 빌드와 실행이 연속으로 진행됨.
  • 오류 메시지와 터미널의 실행 결과를 확인하여 프로그램이 의도대로 동작하는지 검증함.

올바른 실습 방법

  • 예제 코드를 직접 입력하고 작은 부분을 바꾸면서 결과를 예측함.
  • AI 코딩 도우미의 설명과 수정안은 그대로 믿지 않고, 코드를 읽은 뒤 직접 실행하여 확인함.
  • 오류가 발생해도 실패로 여기지 않고 문제의 원인을 찾는 학습 자료로 활용함.

AI 시대에서 왜 우리는 C 프로그래밍을 배워야 하는가?

질문의 수준이 AI 활용 수준을 결정함

질문의 차이가 곧 결과의 차이

  • 👶 초보자의 프롬프트: "계산기 프로그램 작성해 줘!"
  • 👨‍💻 전문가의 프롬프트: "스택(Stack)을 활용한 후위 표기법 기반의 계산기 프로그램을 작성해 줘. 연산 로직은 별도의 헤더 파일로 모듈화하고, 함수 포인터 배열을 사용해 새로운 연산자 확장이 용이하도록 구조화해 줘. 0으로 나누는 것과 같은 예외 처리 로직을 포함하고, 모든 함수에는 Doxygen 스타일의 주석을 달아 줘."

프로그래밍을 배워야 하는 이유

  • AI에게 코딩을 맡기더라도, 작동 원리를 아는 사람과 모르는 사람의 질문(프롬프트) 수준은 완전히 다름.
  • C 프로그래밍을 통해 컴퓨터의 구조를 깊이 이해하면, AI에게 훨씬 더 정교하고 효과적인 질문을 할 수 있음.
  • 토큰 수도 줄여서 돈도 절약할 수 있음.

프로그래밍을 배우는 것은 AI를 똑똑하게 부리기 위한 '질문하는 힘'을 기르는 과정임.
