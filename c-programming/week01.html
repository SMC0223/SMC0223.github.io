프로그래밍 언어?

C언어

  • 1970년대 초, 데니스 리치가 개발(The C Programming Language)
  • 운영체제, 임베디드 시스템 프로그래밍 등에 자주 사용

C 언어 특징

  • 절차지향 언어, 빠르고 효율적
  • 간결한 문법 + 직접 메모리 제어 가능
  • 이식성이 매우 높음

주요 활용 분야

  • 운영체제 개발, 임베디드 시스템
  • 컴파일러 개발
  • 실시간 모터 제어기, 로봇 제어기 등

1세대 언어(1GL)

  • 기계어: CPU가 직접 처리할 수 있는 2진수(0과 1) 형태의 언어.

2세대 언어(2GL)

  • 어셈블리어: 기계어 명령을 간단한 영문 기호(ADD, SUB 등)로 매핑하여 인간의 관점에서 사용하기 편해진 저급 프로그래밍 언어.
  • 어셈블러를 통해 기계어로 번역됨.

3세대 언어(3GL)

  • 고급 프로그래밍 언어: C, C++, Java, Python, Pascal 등 인간이 이해하기 쉬운 문장 형태로 작성하는 언어.
  • 컴파일러나 인터프리터를 통해 기계어로 번역됨.

4세대 언어(4GL)

  • 비절차적·특수 목적 언어: SQL, PL/SQL, ABAP, Unix Shell, R, Halide, Oracle Reports 등.
  • '어떻게(How)'가 아니라 '무엇을(What)' 할지 명시하여 개발 생산성을 극대화한 언어.

5세대 언어(5GL)

  • 인공지능 및 제약 조건 기반 언어: Prolog, OPS5, Mercury, CVXGen, Geometry Expert 등.

C 프로그램의 실행 과정

%%{init: {"themeVariables":{"fontSize":"20px"},"flowchart":{"padding":14,"nodeSpacing":32,"rankSpacing":36}}}%% flowchart LR A[소스 코드 작성 <br>main.c] -- 컴파일 --> B[목적 파일 <br>main.o] B -- 링크 --> C[실행 파일] C -- 실행 --> D[출력 결과]

  • 컴파일(Compile)은 작성한 C 소스 코드를 컴퓨터가 처리할 수 있는 목적 파일(Object File)로 변환하는 과정. 이 과정에서 문법 오류와 자료형 등을 검사.

  • 링크(Link)는 생성된 목적 파일과 필요한 라이브러리를 서로 연결하여 하나의 실행 파일(Executable File)을 만드는 과정.

  • 실행(Execute)은 완성된 실행 파일을 메모리에 불러와 CPU가 명령어를 순서대로 수행하는 과정.

printf 함수

  • printf("문자열") 과 같이 문자열을 입력 받고 화면에 출력.

주석이란?

  • 컴퓨터가 아닌 사람에게 가독성 향상 및 정보 전달을 위해 적는 문장.
  • 컴파일러는 주석을 번역하지 않음.
  • 주석 삽입은 코드의 가독성, 유지보수성 및 재사용성 향상을 위해 필수.
  • AI를 활용하는 경우에도 주석을 넣어 효율적인 코드 생성이 가능.
  • 언어마다 주석문은 다르며 c언어의 경우 한줄 주석은 //내용, 여러줄 주석은 /* 내용 */.

바람직한 주석 작성법

  • 모든 문장마다 주석을 작성하면 오히려 코드가 복잡하고 지저분해져 가독성을 떨어뜨릴 수 있음.

  • 주석은 코드만으로 알기 어려운 목적, 의도, 제약사항 및 사용 방법을 중심으로 작성.

  • 소스 파일의 시작 부분에는 파일 전체를 설명하는 머리말 주석(Header Comment)을 작성하는 것이 좋음.

  • 머리말 주석에는 다음과 같은 정보를 포함할 수 있음.

    • 파일에 대한 간략한 설명
    • 파일에서 구현한 주요 기능
    • 최초 작성자
    • 최초 작성일 및 최종 수정일
    • 주요 변경 내역
    • 미완성 기능 및 알려진 버그
    • 저작권 및 라이선스 정보

  • 함수에는 함수의 목적, 입력값, 반환값 등을 설명하는 주석을 작성하면 유지보수와 재사용에 유리함.

  • 좋은 주석은 왜 그렇게 작성되었는지를 설명하는 것이 중요함.

c
/*
 * File        : sum.c
 * Description : 두 정수의 합을 계산하는 예제 프로그램
 * Author      : 홍길동
 * Created     : 2026-09-05
 * Last Update : 2026-09-05
 *
 * Functions
 *   - sum() : 두 정수의 합을 계산
 *
 * Known Issues
 *   - 없음

/**
 * @brief 두 정수의 합을 계산하는 함수
 *

 * @param b 두 번째 정수
 * @return 두 정수의 합
 */
int sum(int a, int b)
{
    return a + b;
}

오늘의 핵심

프로그래밍과 C언어

  • 문제 분석 → 해결 절차 설계 → 프로그래밍 언어로 표현

  • C언어의 주요 활용 분야: 운영체제, 임베디드 시스템, 실시간 제어기, 로봇 제어기

  • C 프로그램의 시작점: main() 함수

  • 기본 문법 요소: #include, return, 세미콜론(;)

작성한 코드가 실행되기까지

  • 소스 코드(.c) → 컴파일(Compile) → 목적 파일 → 링크(Link) → 실행 파일

  • #include <stdio.h> : 표준 입출력 함수 사용

  • printf() : 화면 출력

  • 주요 형식 지정자: %d 정수, %f 실수, %c 문자, %s 문자열

올바른 코드 작성 방법

  • 불필요한 주석보다 목적, 의도, 제약사항, 사용 방법 중심의 주석 작성

  • 소스 파일: 머리말 주석을 통한 파일 정보 기록

AI 시대에서 왜 우리는 C 프로그래밍을 배워야 하는가?

질문의 수준이 AI 활용 수준을 결정함

질문의 차이가 곧 결과의 차이

  • 👶 초보자의 프롬프트: "계산기 프로그램 작성해 줘!"
  • 👨‍💻 전문가의 프롬프트: "스택(Stack)을 활용한 후위 표기법 기반의 계산기 프로그램을 작성해 줘. 연산 로직은 별도의 헤더 파일로 모듈화하고, 함수 포인터 배열을 사용해 새로운 연산자 확장이 용이하도록 구조화해 줘. 0으로 나누는 것과 같은 예외 처리 로직을 포함하고, 모든 함수에는 Doxygen 스타일의 주석을 달아 줘."

프로그래밍을 배워야 하는 이유

  • AI에게 코딩을 맡기더라도, 작동 원리를 아는 사람과 모르는 사람의 질문(프롬프트) 수준은 완전히 다름.
  • C 프로그래밍을 통해 컴퓨터의 구조를 깊이 이해하면, AI에게 훨씬 더 정교하고 효과적인 질문을 할 수 있음.
  • 토큰 수도 줄여서 돈도 절약할 수 있음.

프로그래밍을 배우는 것은 AI를 똑똑하게 부리기 위한 '질문하는 힘'을 기르는 과정임.
