변수의 값과 주소

c
int value = 10;
printf("%d\n", value);
printf("%p\n", (void *)&value);
  • value: 변수에 저장된 정수 값. %d로 출력.
  • &value: 변수의 주소. &는 주소 연산자.
  • 주소는 %p로 출력. (void *)는 출력 서식에 맞추는 변환.

실제 주소의 숫자는 실행 환경에 따라 다름. 주소 자체를 외우지 않고 같은 대상인지 확인.

선언에서의 *: 포인터 변수 선언

c
int *p;
  • int: 가리킬 대상의 자료형.
  • 선언의 *: p를 포인터 변수로 선언하는 표시.
  • 변수의 이름은 p. *p 전체가 변수 이름인 것은 아님.
  • 이 문장은 포인터 변수 선언. 대상의 값을 읽거나 바꾸는 동작은 없음.

함수 안에서 위와 같이 선언한 지역 포인터는 유효한 주소를 대입한 뒤에 값을 읽음.

02. 포인터로 값을 읽고 변경

역참조 · 원본의 값 변경 · 포인터 자신의 주소

C ProgrammingWEEK 08

표현식에서의 *: 가리키는 대상에 접근

c
int value = 10;
int *p = &value;          // 포인터 변수 선언과 초기화
printf("%d\n", *p);       // 역참조하여 값 읽기
  • p: value의 주소를 저장한 변수.
  • 표현식의 *: 포인터가 가리키는 대상에 접근하는 역참조 연산자.
  • *p: 저장된 주소를 따라 원본 value에 접근. 위 출력 결과는 10.

선언의 *는 변수의 종류를 지정. 표현식의 *는 저장된 주소를 통해 대상에 접근.

실행 순서: a의 값이 5 → 10 → 15로 변경

가리키는 대상 변경과 대상의 값 변경

Code

c
int main(void) {
    int value = 10;
    int other = 30;
    int *p = &value;
    return 0;
}
  • 두 그림 모두 왼쪽의 같은 초기 상태에서 각각 실행.
  • p = &other;: 가리키는 대상 변경.
  • *p = other;: value의 값 변경.

다른 포인터에 저장된 주소값 복사

Code

c
int main(void) {
    int value = 10;
    int *p = &value;
    int *q = p;
    return 0;
}
  • p와 q는 서로 다른 포인터 변수.
  • 같은 주소값을 저장하여 동일한 value에 접근.

값 복사와 포인터를 통한 원본 변경

Code

c
int main(void) {
    int value = 10;
    int copy = value;
    int *p = &value;
    *p = 20;
    return 0;
}
  • value의 값은 20으로 변경.
  • 별도 공간에 복사한 copy의 값은 10 유지.

포인터를 사용하는 이유

  • 주소를 통해 기존 변수의 값을 읽거나 변경 가능.
  • 주소값을 복사한 여러 포인터가 같은 원본에 접근 가능.
  • 함수에 주소값을 전달하여 원본을 다루는 방법으로 확장 가능.

큰 자료의 복사를 줄이는 설계에도 활용. 구체적인 효과는 자료의 크기와 사용 방식에 따라 달라짐.
