조건식 문제: 차단기 Y

다음 [조건]에 따라 기차가 생산 공장을 출발하여 완성품 창고로 가기 위한 차단기 Y의 조건식으로 옳은 것은? [3점]

[조건]

  • 기차는 전진만 한다.
  • 철로 조작 레버 A와 B는 올리면 값은 1이 되고 바깥쪽 철로에 연결되며, 내리면 값은 0이 되고 안쪽 철로에 연결된다.
  • 생산 공장에서 완성품 창고로 가는 철길이 바르게 연결되면 차단기 Y는 1이 되고, 그렇지 않으면 0이 된다.

else if: 여러 조건을 순서대로 검사

c
int battery = 20;
if (battery < 20) {
    printf("DANGER\n");
} else if (battery < 50) {
    printf("CAUTION\n");
} else {
    printf("NORMAL\n");
}
  • 위에서부터 검사하여 처음 참인 블록 하나만 실행함.

  • 마지막 else는 앞의 모든 조건이 거짓일 때 실행됨.

0~100 범위의 입력 기준. 현재 값 20은 CAUTION 출력. 마지막 else가 없고 모든 조건이 거짓이면 어느 블록도 실행하지 않음.

C ProgrammingWEEK 04

논리 연산으로 범위 표현

판단 조건식
각도가 -90 이상 90 이하 angle >= -90 && angle <= 90
각도가 -90 미만 또는 90 초과 angle < -90 || angle > 90
정지 신호가 없는 상태 !stop
  • &&: 양쪽 조건을 모두 만족할 때 참.
  • ||: 하나 이상의 조건을 만족할 때 참.
  • !: 참·거짓을 반전함.
  • 수학의 범위 표기 -90 <= angle <= 90을 C 조건식에 그대로 사용하지 않음.

연속 비교는 (-90 <= angle)의 결과인 0 또는 1을 다시 90과 비교하므로 의도한 범위 검사가 되지 않음.

정수·문자 값과 일치하는 case에서 실행 시작

C ProgrammingWEEK 04
WEEK 04

switch 기본 구조

c
int mode = 2;
switch (mode) {
    case 1:
        printf("MANUAL\n");
        break;
    case 2:
        printf("AUTO\n");
        break;
    default:
        printf("UNKNOWN MODE\n");
        break;
}
  • 일치하는 case로 이동. 일치하는 값이 없으면 default로 이동.
  • break는 현재 switch를 빠져나가는 역할.
  • 현재 값 2는 AUTO 출력. default도 없고 일치하는 case도 없으면 switch 본문을 건너뜀.

switch에서 사용할 수 있는 조건

항목 사용 기준
switch (식) 정수형 식 사용. char도 사용 가능
case 값: 정수 상수식 사용. 같은 값 중복 불가
case 'A': 문자 상수 사용 가능
default: 일치하는 case가 없을 때 실행. 생략 가능
  • double 값이나 문자열을 직접 비교하는 용도로 사용 불가.
  • 값의 범위는 if로 비교. case에는 1, 2, 'A'처럼 구분할 값 지정.

C11 기준으로 일반적인 const int 지역 변수는 case의 정수 상수식으로 사용 불가.

여러 case에서 같은 동작 실행

c
char command = 'S';
switch (command) {
    case 's':
    case 'S':
        printf("STOP\n");
        break;
    default:
        printf("UNKNOWN\n");
        break;
}
  • 소문자 s와 대문자 S를 같은 동작으로 연결함.
  • case 's': 다음에 바로 case 'S':를 배치하여 코드 공유.
  • 문자 입력에는 scanf(" %c", &command); 사용.

05. 계산기를 만들어보자

입력 → 연산 선택과 계산 → 결과 출력

C ProgrammingWEEK 04
WEEK 04

계산기 1: scanf로 세 값 입력

c
double value1 = 0.0, value2 = 0.0;
double result = 0.0;
char op = ' ';
scanf("%lf %c %lf", &value1, &op, &value2);
입력 순서 저장할 변수 형식 지정자 입력 예
첫 번째 값 value1 %lf 10.5
연산자 op %c /
두 번째 값 value2 %lf 2.0
  • 입력 예: 10.5 / 2.0. 세 항목을 한 번의 scanf로 입력.
  • %c 앞의 공백은 입력에 남은 공백·줄바꿈을 건너뛰는 역할.

이번 실습은 올바른 숫자와 +, -, *, / 입력 사용. 수는 -1000~1000 범위, 나눗셈의 두 번째 값은 절댓값 0.01 이상 사용.

계산기 2: switch로 연산 선택

c
switch (op) {
    case '+':
        result = value1 + value2; break;
    case '-':
        result = value1 - value2; break;
    case '*':
        result = value1 * value2; break;
    case '/':
        result = value1 / value2; break;
    default:
        return 1;
}
  • 입력한 op와 일치하는 case 선택.
  • '+', '-', '*', '/'는 문자 상수.
  • 계산한 값을 공통 변수 result에 저장.
  • break로 switch를 빠져나와 출력 단계로 이동.

코드는 main 함수 안에 배치. 지원하지 않는 연산자는 default의 return 1로 프로그램 종료.

라인트레이서: 센서값과 주행 동작

  • 앞쪽 센서 2개 사용: 검은 선 감지 시 1, 흰 바닥 감지 시 0.
  • 두 센서는 주행선 양옆의 흰 바닥에 배치. 세로 정지선에서 두 센서 모두 검은색 감지.
  • 왼쪽·오른쪽은 로봇의 진행 방향 기준.
  • if로 두 센서값을 직접 판단하거나, 아래처럼 2비트로 묶어 switch에 활용 가능.
c
int sensor_bits = (left << 1) | right;
왼쪽 센서 오른쪽 센서 2비트 표현 sensor_bits 선택 동작
0 0 00 0 직진
0 1 01 1 우회전
1 0 10 2 좌회전
1 1 11 3 정지선에서 정지

선이 두 센서 사이에 있으면 00. 선을 완전히 벗어나도 00이 될 수 있으므로 궤적 확인 필요. 좌회전은 오른쪽 바퀴를 더 빠르게, 우회전은 왼쪽 바퀴를 더 빠르게 회전시켜 구현.

라인트레이서: 조건에 따라 두 바퀴 속도 선택

  • if / else if / else 또는 switch 중 선택하여 작성.
  • 센서값에 따라 좌우 바퀴 속도를 변수에 저장.
  • 센서값이 모두 0이면 직진, 모두 1이면 두 바퀴 속도를 0으로 설정하여 정지선에서 정지.
  • 두 속도가 같으면 직진, 오른쪽이 빠르면 좌회전, 왼쪽이 빠르면 우회전.
  • 입력은 left, right 순서로 각각 0 또는 1 사용. 바퀴 속도는 0~255 정수 사용.
  • if는 센서값을 직접 비교 가능. switch는 두 값을 비트로 묶은 sensor_bits 활용 가능.
  • 다음 실습의 주석 위치에 속도를 선택하는 코드 작성. printf로 좌우 속도 두 개만 출력.
  • 코드 적용 → 주행 시작 또는 랩타임 도전 순서로 결과 확인. 코드 적용 시 인터넷 연결 필요.
